Задание джуниору (в данном случае я отвечу за менеджера на свои вопросы):

Необходимо разработать приложение на Laravel, где через html-форму можно будет загрузить Excel-файл в формате .xslx, файл содержит три колонки: id, name и date. Содержимое колонок необходимо валидировать по правилам:
    • ID обязателен и должен быть только числом, допускаются дубликаты;
    • Имя обязательно;
    • Дата обязательна.

Если хотя бы одно из полей не проходит валидацию, мы пропускаем всю строку. В конце импорта необходимо записать ошибки в файл result.txt в формате <номер строки> - <ошибка1>, <ошибка2>. Валидные данные мы сохраняем в базу. Не забудь удалить временный загруженный файл.

Прогресс записи в базу нужно логгировать в Redis в формате «уникальный ключ: количество обработанных строк», пропущенные строки мы тоже считаем. Для ускорения импорта предлагаю делать запись по 1000 записей за раз. На каждую запись в БД создаем Laravel Echo event, где отдаём число сколько на данный момент обработано строк.

Парсинг файла предлагаю делать пакетом maatwebsite/excel (https://laravel-excel.com/), валидацию нужно написать свою. Делаем сначала «грубое валидирование» на уровне контроллера средствами Laravel (проверяем есть файл), остальную логику делаем отдельным сервисом. По успешному завершению импорта нужно отдавать JSON в виде: {success:true} c кодом 200, внутри сервисов предусмотреть выброс Exception, а запись в базу делать нужно транзакцией во избежании частичной записи данных.

Также необходимо реализовать REST API (например, по эндпоинту /api/data), который будет отдавать содержимое БД c группировкой по date:
[
{
date: ‘xxxx-xx-xx’,
items: [
{
…
},
{
…
}
]
}
]

Его мы так же делаем в виде отдельного сервиса, авторизацию пока не проверяем.

Создаём тесты на:
    • Правильную отдачу данных через API;
    • Запись в Redis;
    • Запись в БД;
    • Создание event`a;
    • Создание файла result.txt
